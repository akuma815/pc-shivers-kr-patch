The file xdelta3decode.exe is the full official xdelta3.exe renamed locally;
the minimal upstream decoder does not include the LZMA codec used by this patch.

The installer reads Malgun Gothic from the user's Windows installation and
makes a local unchanged game copy for this Windows runtime. It does not install
a font system-wide, modify font data, or distribute the font file.
Microsoft guidance: https://learn.microsoft.com/en-us/typography/fonts/font-faq

The custom subtitle overlay is separate from the original game's English
subtitle option. Always start with Shivers Korean.exe. The launcher enforces
native subtitles=false and --no-subtitles without modifying the global
ScummVM configuration. Do not re-enable original subtitles in the game options.

This release candidate is not a claim of complete full-game translation or QA.
Known intentionally untranslated graphics are unchanged. Existing game saves
are not converted between target names or between original SCI and ScummVM.
