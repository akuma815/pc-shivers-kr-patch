사전 준비
• Windows 10/11 64비트, .NET Framework 4.8, 여유 공간 1GB 이상.
• 정품 Shivers 영문 Windows 1.02의 게임 데이터를 쓰기 가능한 폴더에 준비하세요.
  RESSCI.000, RESMAP.000 및 MOVIES 폴더가 있는 위치를 선택합니다.
  ISO 파일이나 읽기 전용 CD 드라이브는 직접 패치할 수 없습니다.
• 실행 중인 게임/ScummVM을 종료하고 중요한 저장은 별도로 백업하세요.
• 맑은 고딕이 Windows에 설치돼 있어야 합니다. 폰트 자체는 배포하지 않습니다.

ScummVM 안내
• 한국어 음성 자막용 커스텀 ScummVM이 포함돼 있어 별도 설치는 필요 없습니다.
• 일반 ScummVM이나 원본 SIERRAW.EXE로 실행하면 한글 자막이 정상 동작하지 않습니다.
• VCRUNTIME/MSVCP DLL 오류가 나면 Microsoft Visual C++ v14 재배포 패키지(x64)를 설치하세요.
  공식 다운로드: https://aka.ms/vc14/vc_redist.x64.exe

사용 방법
1. 배포 ZIP을 게임 폴더 밖에 모두 풀고 이 프로그램을 실행합니다.
2. 게임 데이터 폴더를 선택합니다. 이어서 플레이하려면 기존 저장 폴더도 선택하세요.
   이 패치의 ScummVM 저장 파일 이름은 shivers-ko-full.001 등의 형식입니다.
   다른 target 이름의 저장은 자동 변환하지 않습니다. 원본 Windows판 저장도 지원하지 않습니다.
3. '패치 적용'을 누릅니다. 원본 검사 → 복원 → 검증 → 백업 → 적용 순으로 진행됩니다.
4. 게임 폴더의 Shivers Korean.exe 또는 play.cmd로 시작합니다.
   continue.cmd는 1번 저장을 불러옵니다. 다른 저장은 Old Game에서 선택하세요.

자막과 백업
• 매 실행 시 원본 영어 자막은 끄고 외부 한글 영상·음성 자막을 사용하도록 설정합니다.
  게임 내부 원본 Subtitles 옵션은 켜지 마세요. '자막 끄기' 설정은 원본 영어만 뜻합니다.
• 게임 원본 데이터/영상 및 세이브 파일은 덮어쓰거나 삭제하지 않습니다.
• 교체 대상의 기존 파일은 _shivers_ko_backups의 날짜별 폴더에 보존합니다.
  적용 오류는 자동 복구하며, 중단된 작업은 '백업 복구'로 해당 백업을 선택하세요.
• 이미 설치된 같은 패치를 다시 적용할 수 있습니다. 나중에 바꾼 파일은 복구 시 보호됩니다.
• 원본 게임/더빙/Windows 폰트는 배포물에 포함되지 않습니다. 일부 미번역 항목은 원문 유지입니다.
• 검증 범위: 기존 사용자 번역, 오프닝 자막 설정 및 방명록 맑은 고딕 음성 자막 확인.
  전체 게임의 모든 장면을 새로 검수한 완전 번역판이라는 의미는 아닙니다.
