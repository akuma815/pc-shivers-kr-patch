# 쉬버스 — Windows / 커스텀 ScummVM

Windows / 커스텀 ScummVM **쉬버스** 한글 번역 패치 프로젝트입니다. 박물관을 탐험하고 퍼즐을 푸는 미스터리 어드벤처 게임입니다.

> **현재 최종 배포 후보 v1.0 RC1**

## 다운로드 및 적용 방법

1. 아래 체크섬 또는 상세 안내와 일치하는 원본을 준비합니다.
2. [최종 배포 패치 다운로드](https://github.com/akuma815/pc-shivers-kr-patch/releases/tag/v1.0-rc1)에서 ZIP을 받아 모두 압축 해제합니다.
3. `ShiversKoreanPatch.exe`를 실행해 `RESSCI.000`, `RESMAP.000`, `MOVIES`가 있는 게임 데이터 폴더를 선택합니다.
4. 패치 적용 후 게임 폴더의 `Shivers Korean.exe` 또는 `play.cmd`로 실행합니다.

## 주의사항

- 영문 Windows판 1.02 게임 데이터가 필요합니다.
- 동봉 커스텀 ScummVM을 사용해야 하며 일반 ScummVM·SIERRAW.EXE에서는 정상 동작하지 않습니다.
- Windows의 맑은 고딕이 필요하며 폰트 자체는 배포하지 않습니다.
- 전체 게임의 모든 장면을 새로 검수한 완전 번역판이라는 의미는 아닙니다.
- 원본 게임·BIOS 및 패치가 적용된 게임 이미지는 포함하지 않습니다.
